# AI Mystery Room 🔍

An AI-powered interactive detective game where players investigate fictional mysteries, examine evidence, question suspects, and solve cases using clues and progressive hints generated by Google Gemini AI.

## 1. Project Overview

AI Mystery Room is a full-stack web application designed to provide an interactive detective investigation experience.

Players can generate mysteries based on different categories and difficulty levels. Each mystery contains suspects, evidence, and hints. Players progressively discover evidence and use logical reasoning to identify the culprit.

The application uses Google Gemini AI to generate original mystery scenarios and Node.js to manage investigation progress.

## 2. Objectives

- Develop an AI-powered mystery generation system.
- Provide interactive detective investigation experiences.
- Implement progressive evidence discovery.
- Create a difficulty-based hint system.
- Preserve investigation progress using local JSON storage.
- Build a responsive and user-friendly interface.

## 3. Key Features

### AI Mystery Generation

- Generate original detective mysteries using Google Gemini AI.
- Choose from multiple mystery categories.
- Select Beginner, Intermediate, or Expert difficulty.

### Mystery Categories

- Locked Room
- Missing Artifact
- Mansion Secret
- Museum
- Office
- Secret Identity
- Historical

### Suspect Investigation

- View generated suspects.
- Examine suspect descriptions and alibis.
- Compare information with discovered evidence.

### Evidence Discovery

- Discover evidence progressively.
- Unlock evidence descriptions through investigation.
- Prevent duplicate evidence discoveries.

### Progressive Hint System

- Receive hints one at a time.
- Apply different hint limits based on difficulty.
- Track used and remaining hints.
- Prevent additional hints after reaching the limit.

### Local Data Persistence

- Save generated mysteries in a local JSON file.
- Preserve discovered evidence.
- Preserve revealed hints and hint usage.
- Restore saved mysteries after backend restart.

## 5. System Architecture

The application follows a frontend-backend architecture.

1. The React frontend provides the user interface.
2. The frontend sends API requests to the Express backend.
3. The backend communicates with Google Gemini AI to generate mysteries.
4. The backend validates and processes generated content.
5. Investigation progress is stored in a local JSON file.
6. Saved mystery data is restored when the backend restarts.

## 8. Installation and Setup

### Prerequisites

- Node.js and npm
- Visual Studio Code
- Google Gemini API key

### Step 1: Clone or download the project

Open the project folder in Visual Studio Code.

### Step 2: Install frontend dependencies

```bash
cd frontend
npm install
```

### Step 3: Install backend dependencies

Open another terminal:

```bash
cd backend
npm install
```

### Step 4: Configure environment variables

Create a `.env` file inside the backend folder.

```env
GEMINI_API_KEY=your_gemini_api_key
PORT=5000
```

Replace the placeholder with your own Gemini API key. Never share or commit this key.

### Step 5: Start the backend

From the backend directory:

```bash
npm run dev
```

If the project does not have a `dev` script, use:

```bash
node server.js
```

The backend runs at:

```text
http://localhost:5000
```

### Step 6: Start the frontend

From the frontend directory:

```bash
npm run dev
```

Open the local URL displayed by Vite in your browser.

## 9. Backend API Endpoints

| Method | Endpoint                                           | Description                   |
| ------ | -------------------------------------------------- | ----------------------------- |
| GET    | `/`                                                | Backend health check          |
| POST   | `/api/mysteries`                                   | Generate a new mystery        |
| GET    | `/api/mysteries/:id`                               | Retrieve mystery and progress |
| POST   | `/api/mysteries/:id/evidence/:evidenceId/discover` | Discover evidence             |
| POST   | `/api/mysteries/:id/hint`                          | Request the next hint         |

## 10. Data Persistence

The application uses local JSON file storage instead of a cloud database.

Mystery data is stored at:

```text
backend/data/mysteries.json
```

The backend automatically loads saved mysteries when it starts.

The saved data includes:

- Mystery information
- Suspects and evidence
- Discovered evidence
- Private hints
- Revealed hint history
- Hint usage information
- Hidden solution

The local JSON file should not be uploaded publicly because it contains private game information.
